# 打包说明

## 1. 推荐方式

在 Windows 下执行：

```bash
scripts\\build.bat
```

脚本会自动检查 PyInstaller 并打包 `onedir` 产物。

## 2. 打包输出

默认输出目录：

- `dist/`

可执行文件和依赖会在同一分发目录下。

## 3. 运行时数据

源码版默认使用项目 `data/`；安装版默认使用 `%APPDATA%/LocalMovieWall/data/`，`MML_DATA_DIR` 可覆盖。运行数据包括配置、电影缓存、观看/收藏记录及刮削凭据；不应将个人运行数据打入分发包。

## 4. 分发建议

1. 分发整个 `dist` 目录，不要只拷贝 exe。
2. 升级时保留 `%APPDATA%/LocalMovieWall/data/`；迁移前先备份运行数据。
3. 保持 PyInstaller 生成的 `_internal` 资源目录结构，不单独移动 EXE。

## 5. 常见问题

1. 启动慢
   - 首次启动属于正常现象。

2. 报毒
   - 建议在可信环境签名并加入白名单。

3. 资源缺失
   - 检查打包配置是否包含 `styles`、`logo`；个人 `data` 不加入打包配置。


## 6. 桌面内置刮削依赖

使用 Windows Python 3.11，先安装根目录 `requirements.txt`，其中 Pillow 用于在纯 Python 领域层校验并转换海报。新增刮削模块可由 PyInstaller 静态导入收集；开发验收已核对提供者、服务、Qt 工作台及 Pillow 均在归档中，QSS 资源也已复制。

豆瓣通过系统 Node.js >=22.13 和 npx 调用固定版本 `@marvae24/douban-cli@0.7.0`，Node 不包含在 EXE 分发包中。运行测试版或安装版前，需在目标 Windows 机器上安装 Node；数据源设置中的连接测试可以检查当前环境。

安装版运行数据默认在 `%APPDATA%/LocalMovieWall/data/`，不会从只读安装目录写入；`MML_DATA_DIR` 可覆盖。源码版仍默认项目 `data/`。不要将真实配置、凭据、观看记录或媒体库文件打入分发包。
