# 3.3.1 搜索导航与三站评分修复

- 原导航只有主页选中的一部影片，前后按钮均把索引限制在 0，表现为点击无反应。现在单选入口传入当前可见筛选排序的影片列表，从当前影片开始；多选仍只处理选中队列。首尾不可用方向和写入期间禁用导航，长片名不撑宽窗口。
- 原预览仅合并当前抓取资料和已经确认的来源，没有纳入同身份 NFO 的其他评分，也缺少 TMDB → 豆瓣补充路径。现在同身份的 NFO 评分、来源 ID、已有评分人数进入合并草稿；新身份不继承旧电影评分。相同原名及年份可以识别不同中文译名，明确 ID 冲突仍要求身份替换。
- 完整刮削窗口在预览阶段补充 IMDb，保留豆瓣 → TMDB 的唯一精确关联，并新增 TMDB → 豆瓣的明确 ID/唯一同名同年关联。歧义、年份不符、ID 冲突或来源不可用时不强行合并，保留已取得评分；提供“匹配豆瓣补充评分”，与现有匹配 TMDB 入口对应。确认直接使用完整合并资料，不重建最后一个来源。
- 导航、数值显示及来源操作仅在 UI 线程；评分请求与 NFO 快照/合并均在后台。搜索源与简介源仍可独立选择；手动补充另一站不改变已选简介来源。
- 回归还复现 Windows 文件时钟领先系统时钟 1ms 时，IMDb 新缓存被误判失效并被旧下载覆盖。缓存读取现容忍 1 秒内时钟偏差，仍保持 24 小时过期规则。
