# 网页电影墙体验与桌面刮削一致性

用户七项要求均实施，桌面海报墙布局不变。

1. 网页提供全屏海报墙；选择影片打开带入场/退出过渡的浮动详情，点击空白或 Escape 关闭。详情覆盖在海报墙上，不挤压或重建网格；切换影片保留面板尺寸、滚动与旧内容直到新内容到达，过期请求不生效，尊重减少动态效果设置。
2. 评分顺序固定豆瓣/IMDb/TMDB，卡片按此顺序取有效评分，标题区半透明背景、金色分辨率标识；默认上映日期倒序。领域层将旧英文类型归并中文并去重，筛选与详情一致。
3. 网页播放通过 moviewall:// 专用协议启动客户端默认视频播放器；Windows MSI 注册，入口在单实例锁前处理，仅允许绝对路径/UNC 视频文件，不执行 shell 或任意文件。提供客户端安装/未注册恢复说明。
4. 网页增加 TMM 风格管理列表、详情、搜索刮削和编辑窗口。复用 ScrapeService、media_discovery、持久化与冲突校验，支持新片发现、候选预览、手动确认、跨来源评分/简介、海报、字段选择、补缺/覆盖、重新匹配、批量已确认保存、上一部/下一部。
5. NAS 默认为只读；设置允许明确切换为可写。只有用户确认候选后点保存才写 NFO/海报，使用原样备份、版本校验和回滚。不在真实用户 NAS 上执行验证写入；通过临时 SMB 测试共享验证读写切换和完整保存。
6. 凭据保存在 NUC 刮削配置并掩码返回，API 不信任客户端 metadata 或路径，只接受服务端会话/候选令牌。服务器搜索/预览/写入都在后台任务，取消/失败/歧义/只读有明确反馈；不自动按模糊名称匹配或写盘。
7. Python 回归、前端交互测试（含滚动/DOM 保持）、build/lint、SMB 独立数据验收，部署备份后更新 NUC，交付含播放协议的 3.5.0 MSI，中文提交。

浏览器限制：系统全屏需要用户手势；本地播放器需安装新版客户端并允许浏览器打开专用链接。手机不支持 Windows 播放桥时给出实际可用说明，不声称可播放不受支持的浏览器格式。
