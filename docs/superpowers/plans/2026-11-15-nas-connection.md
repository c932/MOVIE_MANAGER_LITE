# NAS 登录、媒体库与共享库扫描

用户要求修复同步错误，并在网页设置里配置 NAS IP/登录及媒体库。已确认 192.168.50.100 需要账户密码，用户在网页输入，不在对话中发送。

1. 同步错误来自 TMM 烂番茄评分 91 被按十分制拒绝。仅限定 TMDB/IMDb/豆瓣/个人评分为 0–10，其他来源保留有限非负原始值；诊断包含电影与字段。先回归并部署服务器热修复。
2. NUC 安装 cifs-utils/smbclient。独立 root 所有的 Unix socket helper 只允许列出 SMB 共享、只读挂载/断开固定根目录的 SMB 共享；严格验证参数，不使用 shell，不接受任意挂载路径。Web 服务继续 NoNewPrivileges，不开放通用提权命令。密码只存 root 0600 文件，接口不回传，启用的连接重启自动恢复。
3. /nas 接口提供连接状态、测试登录/共享列表、连接/断开、目录选择和媒体库保存。网络操作在后台任务，前端可轮询并展示失败；保存媒体目录不自动扫描。
4. 独立 NASPaths 映射保留共享 UNC 标识，扫描物理挂载路径后转回原始 NAS 路径，避免同一电影重复入库。只更新扫描覆盖范围，保留未选择目录/不可访问目录的既有记录；NAS 不可达不清空共享库。
5. 网页设置提供 IP、端口、用户名、密码、域、共享目录、登录测试、连接状态、目录浏览及多媒体库目录选择。NAS 配置完成后刷新源状态使“扫描 NAS”即时可用；断开/登录失败有明确恢复提示。
6. 临时数据测试覆盖百分制、密码保护、参数注入/路径越界、重启配置、UNC 身份、扫描范围与离线保护。用 NUC 上独立临时 SMB 测试共享验证实际登录和只读挂载，不用或猜测用户密码，不写真实 NAS。
7. 构建并部署前端/服务，系统服务和配置先备份；验证域名 API 与已部署资源。3.4.1 MSI、文档、中文提交。实际 NAS 登录需用户网页输入密码后完成，不能宣称已连接真实 NAS。
