# NUC 共享电影库与网页版

用户批准先交付数据库同步、网页浏览，NAS 挂载及依赖源文件的扫描/编辑/播放后续配置。冲突保留服务器版本并明确提示。桌面电影墙现有布局不改。

## 方案
采用现有 FastAPI + React 服务，在 NUC 127.0.0.1:8010 运行，Caddy 暴露 http://movie.nuc.local。SQLite 保存共享资料与单调递增版本，JSON 保持桌面离线兼容。不采用网络共享 JSON（并发覆盖）或客户端直接连接数据库（离线与网络故障难处理）。

每部电影按规范化 NFO 路径生成跨平台稳定 ID；保存全部电影字段、观看状态、收藏、个人评分。同步不传客户端路径配置、播放器配置、API 凭据。海报独立传输并持久化在服务器；NAS 关闭仍可浏览。UNC 路径作为原始标识保存，不伪装成 Linux 已挂载路径。

桌面设置提供启用、后端地址、仅下载/仅上传/双向、自动同步周期与立即同步。默认关闭；开启后启动和定时后台同步。下载无需扫描 NAS，保留本地离线数据。同步进行时不覆盖期间新发生的本地修改；仅上传不应用服务端资料，仅下载不发送任何元数据/海报。退出等待当前后台任务完成。

版本协议按字段三方比较：上传的基线、当前本机值、当前服务器值。服务器字段已改变则保留服务器并报告冲突；不同字段可合并。首次上传不得覆盖服务器已有同 ID 电影。删除使用墓碑，客户端只有已同步且自己明确删除的记录可请求删除；空库不能清空服务器。服务端实例 ID 防止重建数据库或换地址后误用旧同步游标。

初始导入仅读取本机已有 movie_cache、观看历史、收藏及 .poster_cache；不修改媒体文件，不上传凭据。导入前保存服务端快照；上线前验证影片数量、三站评分、中文国家、系列、海报和客户端三种方向。

## 网页
沿用现有深色电影墙；修复详情截断、系列、海报刷新与无效菜单入口，接通观看/收藏、个人评分、搜索筛选排序、榜单与新片浏览。没有挂载 NAS 时源文件操作显示明确说明。网页和桌面同步都从同一 SQLite 数据库取资料，网页修改立即形成新版本。

## 部署与验证
代码和数据各自独立目录，systemd 自动启动；修改 Caddy 前备份并验证，只添加 movie.nuc.local 站点。测试全部使用临时 MML_DATA_DIR，测试同步冲突/删除/中断/换服务器/方向限制；部署后验证实际域名页面、后端列表和海报 HTTP，重启持久化与浏览器交互。交付新版桌面 MSI，不代安装。
